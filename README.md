# Gesture Invisibility Camera

A real-time computer vision app that makes you look invisible. It saves an empty background, then replaces you with it when you show an open hand.

## How to use
1. Run the program, step out of the camera view and press B to save the background.
2. Step back in and show an open hand to become invisible.
3. Show a fist to appear again. Press Q to quit.

## Run
pip install -r requirements.txt
python gesture_invisibility.py

## Tech stack
Python, OpenCV, MediaPipe, CVZone
